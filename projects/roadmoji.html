Roadmoji Display Controller

A Raspberry Pi + Elgato Stream Deck prototype that lets a driver trigger full-screen visual messages and emojis using physical buttons while media can be managed through a web interface.

Raspberry PiPythonPyQtFlaskStream Deck
Roadmoji Vehicle Display Controller Raspberry Pi + Stream Deck prototype combining physical controls, full-screen media and a web management interface.

Use case

A simple rear-display concept for ride-share/vehicle communication where the normal screen can be replaced temporarily by a button-triggered message or emoji.

Status

Functional personal prototype. It has been bench-tested but is not represented as a completed in-vehicle deployment.

Interaction path

Stream Deck Button→Python Event Logic→ PyQt Full-Screen Renderer→HDMI Display

Design goals

Fast physical control with low operator distraction

Button behavior

Short pressDisplays the selected media temporarily, then returns to the default image.
Long pressSets a selected media item as the persistent default/main image.

Media management

Web uploadA Flask interface supports adding or changing media without editing code on the Raspberry Pi.
Automatic mappingMedia files are discovered and mapped to the Stream Deck button layout for practical use.

Reliability improvements

StartupThe application is designed to launch automatically on boot rather than rely on manual desktop interaction.
Device recoveryOngoing work addresses USB/Stream Deck reconnection and feedback behavior when the device is unplugged/reconnected.
